# bs: Build system based on executables
This project uses [jaandrle/bs: The simplest possible build system using executable/bash scripts](https://github.com/jaandrle/bs).

## Available executables

### bs/docs
Generates documentation.

### bs/lint
Runs linting tools.

### bs/build-cjs.js
Creates non-esm version of the library.

### bs/build
Runs all build scripts.

### bs/npm/lint
NPM helper running linting tools for the project.

### bs/npm/update
NPM helper updating dependencies for the project.
